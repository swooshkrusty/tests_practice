Correct answer: code fragment A runs faster than B.Правильный ответ: фрагмент A работает быстрее B.

A: removeFirst() changes head in O(1); n removals take O(n).
B: deleting index 0 shifts the remaining references; all removals take O(n²).

A: removeFirst() меняет head за O(1); n удалений дают O(n).
B: удаление индекса 0 сдвигает оставшиеся ссылки; все удаления дают O(n²).

B: (n − 1) + (n − 2) + … + 1 = n(n − 1)/2
For 1 million values / Для миллиона значений

A performs 1,000,000 constant-time removals. B performs the same number of deletions plus this many reference shifts:

A выполняет 1 000 000 удалений за постоянное время каждое. B выполняет столько же удалений и дополнительно столько сдвигов ссылок:

1,000,000 × 999,999 ÷ 2
= 499,999,500,000

This counts shifted references, not seconds or individual CPU instructions. The float objects themselves do not need to move.

Это число сдвинутых ссылок, а не секунды или отдельные инструкции процессора. Сами объекты float перемещать не требуется.

Assumptions and animation / Условия и анимация

The LinkedList keeps head and size, so getSize() and removeFirst() are O(1). Python list is an array-based list, and len() is O(1). These are the standard assumptions for this quiz.

LinkedList хранит head и размер, поэтому getSize() и removeFirst() — O(1). Python list основан на массиве, а len() — O(1). Это стандартные условия данного вопроса.

The animation separates deletion and shifting to explain one del operation. The temporary gap is illustrative; Python does not expose a gap between elements. A shift frame represents all remaining references moving left. The panels are not a timing benchmark.

Для объяснения одной операции del анимация разделяет удаление и сдвиг. Временный пропуск — иллюстрация; Python не показывает пробел между элементами. Один кадр сдвига означает перенос всех оставшихся ссылок влево. Панели не являются замером времени.
