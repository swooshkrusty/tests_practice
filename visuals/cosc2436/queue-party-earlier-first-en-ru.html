Correct answer: Queue.Правильный ответ: Queue (очередь).

First In, First Out: A arrives first and leaves first. C arrives last and leaves last.

Первым пришёл — первым ушёл: A пришёл первым и ушёл первым. C пришёл последним и ушёл последним.

Arrival: A → B → C
Leaving: A → B → C
Why not a stack or another option? / Почему не стек или другой вариант?

A stack uses LIFO: C → B → A would leave in reverse arrival order. This does not match “arrive earlier → leave earlier.” A queue uses FIFO, preserving arrival order.

Стек использует LIFO: участники ушли бы C → B → A, в обратном порядке. Это не соответствует правилу «пришёл раньше → ушёл раньше». Очередь использует FIFO и сохраняет порядок прихода.

An array, vector, or LinkedList can be used to implement a queue, but these names alone do not specify FIFO behavior. Queue directly names the access rule required here.

Массив, vector или LinkedList можно использовать для реализации очереди, но сами эти названия не задают поведение FIFO. Именно Queue обозначает нужное здесь правило доступа.
