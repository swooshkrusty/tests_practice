addLast(60): create a node, set tail.next to that node, then update tail. No traversal. Constant time: O(1).

Why O(1)? / Почему O(1)?

This implementation stores a tail reference. For a nonempty list, create a node with next = None, set tail.next = newNode, then tail = newNode. Update size if tracked. The number of operations does not depend on the number of existing nodes.

Список хранит ссылку tail. Для непустого списка создаём узел с next = None, выполняем tail.next = newNode, затем tail = newNode. Если есть счётчик размера, увеличиваем его. Число операций не зависит от длины списка.

Empty list / Пустой список: head = tail = newNode — also O(1) / тоже O(1).

Without a stored tail / Без ссылки tail: finding the last node requires traversal, O(n) / поиск последнего узла требует обхода, O(n).

O(1) means constant work, not exactly one operation or one second.
O(1) означает постоянный объём работы, а не одну операцию или одну секунду.
