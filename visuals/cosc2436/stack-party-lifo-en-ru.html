Last In, First Out: C arrives last and leaves first. A arrives first and leaves last.

Последним пришёл — первым ушёл: C пришёл последним и ушёл первым. A пришёл первым и ушёл последним.

Arrival: A → B → C
Leaving: C → B → A
Why not a queue or list? / Почему не очередь или список?

A queue uses FIFO (First In, First Out): A → B → C would leave in the same order they arrived. This contradicts the party rule.

Очередь использует FIFO (первым пришёл — первым ушёл): участники ушли бы A → B → C, в порядке прихода. Это противоречит правилу вечеринки.

A list or linked list can be used to implement a stack, but neither name alone specifies LIFO behavior. Stack is the data structure whose access rule directly matches this question.

Обычный или связный список можно использовать для реализации стека, но сами эти названия не задают правило LIFO. Именно стек напрямую соответствует условию вопроса.
