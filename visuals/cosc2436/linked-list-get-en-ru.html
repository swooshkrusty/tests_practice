Why O(n)? / Почему O(n)?

For index i, follow i next pointers from head: Θ(i + 1) work. At the last index, i = n − 1, so the worst case is Θ(n), commonly stated as O(n). Getting index 0 takes O(1).

Для индекса i нужно пройти i ссылок next от head: Θ(i + 1) работы. Последний индекс — n − 1, поэтому худший случай — Θ(n), обычно пишут O(n). Доступ к индексу 0 — O(1).

Python list / array: items[i] uses direct indexed access, O(1). Прямой доступ по индексу, без прохода по узлам.
