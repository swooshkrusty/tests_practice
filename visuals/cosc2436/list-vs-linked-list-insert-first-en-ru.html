A · Python list

Correct answer: code fragment B runs faster than A.Правильный ответ: фрагмент B работает быстрее A.

A: inserting at the front shifts every existing reference: O(n) per insertion.
B: inserting at the head updates a fixed number of links: O(1) per insertion.

A: вставка в начало сдвигает все существующие ссылки: O(n) на вставку.
B: вставка перед head меняет постоянное число ссылок: O(1) на вставку.

100,000 insertions / 100 000 вставок

Let N be the starting size and k the number of insertions. The list grows after each insertion, so A shifts N, then N + 1, …, N + k − 1 references.

Пусть N — начальный размер, k — число вставок. После каждой вставки список растёт, поэтому A сдвигает N, затем N + 1, …, N + k − 1 ссылок.

A: kN + k(k − 1)/2 → O(kN + k²)
B: k × O(1) → O(k)

Small example: start with [1.1, 2.2, 3.3], then insert i = 0, 1, 2. Both end as [2, 1, 0, 1.1, 2.2, 3.3]. Each new value goes before the previous ones.

Маленький пример: начинаем с [1.1, 2.2, 3.3], затем вставляем i = 0, 1, 2. Оба результата: [2, 1, 0, 1.1, 2.2, 3.3]. Каждое новое значение встаёт перед предыдущими.

Python list stores references; the float objects themselves need not move. The gap and shift are explanatory phases of one insert operation, not an exposed intermediate Python state. Extra capacity allocation does not remove the required front shifts.

Python list хранит ссылки; сами объекты float перемещать не нужно. Пропуск и сдвиг — поясняющие фазы одной операции insert, а не доступное промежуточное состояние Python. Выделение дополнительной памяти не отменяет сдвиги при вставке в начало.

The LinkedList has a head reference and handles index 0 directly. New-node allocation is treated as O(1) in the usual model. The chain is drawn in logical order; existing nodes are not shifted in memory. This is an operation illustration, not a timing benchmark.

LinkedList хранит head и обрабатывает индекс 0 напрямую. В обычной модели выделение узла считается O(1). Цепочка показана в логическом порядке; существующие узлы не сдвигаются в памяти. Это иллюстрация операций, а не замер времени.
