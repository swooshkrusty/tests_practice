Why O(n²)? / Почему O(n²)?

This example always chooses the first element as pivot. For sorted, distinct values, that pivot is the smallest. After placing it, the recursive sublists contain 0 and m − 1 elements, where m is the current sublist size.

В этом примере pivot — всегда первый элемент. В отсортированном списке различных значений он самый маленький. После его установки для рекурсии остаются части размера 0 и m − 1, где m — размер текущего подсписка.

Each partition scans the remaining elements. In the illustrated model, each other value is compared with the pivot once: (n − 1) + (n − 2) + … + 1 = n(n − 1)/2 = Θ(n²). Exact comparison counts vary by partition implementation; the worst-case growth remains quadratic.

При каждом разделении просматриваем оставшиеся элементы. В показанной модели каждый сравнивается с pivot один раз: (n − 1) + (n − 2) + … + 1 = n(n − 1)/2 = Θ(n²). Точное число сравнений зависит от реализации, но худший случай остаётся квадратичным.
